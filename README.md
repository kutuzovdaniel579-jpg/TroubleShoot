# 🚨 TroubleShooter

TroubleShooter is een lichte, dynamische foutpagina die automatisch informatie toont op basis van URL‑parameters.  
De pagina ondersteunt meerdere talen en kan gebruikt worden voor websites die nog in ontwikkeling zijn, tijdelijk offline zijn of specifieke foutcodes willen tonen.

---

## ✨ Features

- Dynamische foutcodes via URL‑parameters  
- Meertalige ondersteuning (EN, NL, FR)  
- Automatische taalkeuze via `?lang=`  
- Custom titel, beschrijving en eigenaar  
- Volledig client‑side, geen backend nodig  
- Werkt op GitHub Pages
